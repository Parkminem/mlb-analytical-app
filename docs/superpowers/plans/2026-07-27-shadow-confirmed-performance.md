# Shadow Confirmed Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make confirmed-lineup shadow freezes fast after one strict checkpoint build while preserving exact forecast, review, calibration, lineage, and append-only ledger behavior.

**Architecture:** Add deterministic lossless encoding at the ledger boundary, a rebuildable checkpoint that indexes validated ledger record offsets, and one lock-scoped pregame session that performs lookup and append without repeatedly reconstructing historical forecast arrays. The operator checks complete exact replay before simulation and otherwise runs the unchanged 20,000-game forecast.

**Tech Stack:** Python 3.14, frozen dataclasses, append-only JSONL, SHA-256, zlib, base64, Pydantic 2, Typer, pytest.

## Global Constraints

- Keep `SimulationConfig.simulations == 20_000`.
- Do not change any baseball evidence, model weight, threshold, market decision, forecast seed, probability, interval, review classification, or calibration output.
- Keep historical JSONL records readable without rewriting them.
- Keep the JSONL ledger authoritative; checkpoint data is rebuildable acceleration state only.
- Keep exact capture lineage, idempotency, active-head CAS, and conservative crash recovery.
- Keep existing live-source and Savant daily-cache policies unchanged.
