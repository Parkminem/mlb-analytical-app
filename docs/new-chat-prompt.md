# New Chat Prompt

Use this prompt if a future environment does not automatically load the repository's `AGENTS.md`.

```text
이 저장소의 MLB 분석 모델을 사용해줘.

먼저 AGENTS.md와 docs/model.md를 읽고, 사용자가 명시적으로 모델 수정을 요청하지 않는 한 규칙을 절대 수정하지 마.

라인업은 RotoWire 확정 라인업을 우선하고, 미확정이면 RotoWire 예상 라인업을 사용해. 공식 MLB 선발과 오프너/벌크 구조를 확인하고, Baseball Savant/Statcast로 양 팀 모든 타자의 구종+구속 대응력을 투수 좌우 및 예상 타석 기준으로 분석해.

캐시는 Savant/Statcast 과거 구종·구속 표본에만 24시간 단위로 사용해. MLB 공식 일정/선발/오프너/벌크, RotoWire 라인업, 배당/O-U 기준점, 박스스코어/불펜 사용량은 매 분석마다 실시간으로 새로 조회해.

기본 출력은 F5 / ML / +1.5 / O/U이며, 소수배당을 사용해. 불펜 연투·휴식·필승조 가용성과 구간별 품질, 최근 타격 흐름, 선발 안정성, 심판을 포함해. 날씨는 내가 제공하거나 요청할 때만 반영해.

불펜은 전날 총투구수보다 역할 분류를 먼저 봐. 마무리/셋업/핵심 좌우 매치업 투수의 30구 이상, 2연투, 3연투는 ML/+1.5에 직접 반영하지만, 롱릴리프/하위 불펜의 30구 이상은 별도 분류하고 필승조 피로처럼 말하지 마.

하위/롱릴리프가 전날 크게 맞았더라도 필승조가 쉬었다면 그건 불펜 피로가 아니라 필승조 가용성 보존으로 봐. 하위 불펜 붕괴는 선발이 짧게 내려가거나 하위 불펜 노출이 커지는 구조에서만 후반 실점/오버 꼬리 리스크로 반영하고, 상대 ML/+1.5 근거로 자동 사용하지 마.

최종 우선순위는 한 경기에서 하나만 고를 필요가 없어. 서로 독립적으로 검증된 마켓이면 승패+언더오버 또는 핸디캡+언더오버를 같은 경기에서 함께 우선순위에 올려도 돼. 다만 ML과 +1.5처럼 같은 사이드 엣지를 중복 등재하지는 말고, 같은 경기 조합은 방향성이 서로 충돌하지 않을 때만 사용해.

요약 표에서는 같은 경기의 ML과 +1.5를 동시에 활성 후보처럼 표기하지 마. 둘 다 가능하면 더 확률이 높거나 모델 점수가 높은 사이드 계열 하나만 고르고, 나머지는 pass 또는 리뷰 전용으로 처리해. 예를 들어 ML은 강도 제한이고 +1.5가 더 안전하면 표에는 +1.5만 남겨.

같은 경기에서 사이드/핸디와 오버를 같이 올릴 때는 오버의 독립 경로를 반드시 확인해. 한쪽 타선의 구종+구속 플러스만으로 오버를 올리지 말고, 양 팀 득점 경로나 불펜 노출, 선발 붕괴 리스크가 따로 있어야 해. 낮은 기준점 오버는 특히 양 팀 모두 득점 경로가 있어야 하고, 상대 선발이 Wheeler/Gilbert급으로 K/BB와 6이닝 안정성이 강하면 핸디와 오버 강도를 낮춰.

기준점이 9.5 이상인 오버는 더 엄격하게 검증해. 양 팀 구종+구속 플러스만으로는 부족하고, 최근 장타/볼넷 전환과 함께 선발 붕괴/커맨드 리스크, 하위 불펜 노출, 또는 내가 제공한 타자 친화적 날씨/구장 근거 중 하나가 추가로 있어야 우선순위에 올려. 선발들이 K/BB 안정성과 6이닝 경로를 갖고 있으면 오버를 먼저 캡해.

기준점이 10.5 이상인 오버는 한쪽 타선만 강하면 올리지 마. 양 팀 모두 독립 득점 경로가 있어야 하고, 한쪽이 구종+구속 적합도, 출루 압박, 최근 득점 전환 중 하나라도 뚜렷하게 약하면 오버는 pass 또는 리뷰 전용으로 내려.

최근 선발 등판에서 0볼넷 또는 저볼넷, 강한 K/BB, 현실적인 6이닝 경로가 보이면 시즌 WHIP/HR 리스크나 구종+구속 플러스만으로 얇은 오버를 올리지 마. 이 경우 오버는 양 팀의 독립 득점 경로, 볼넷/출루 압박, 하위 불펜 노출, 또는 타자 친화적 환경이 추가로 확인될 때만 유지해.

기준점 7.5 이하의 낮은 언더는 선발 duel처럼 보여도 최근 상대 타선의 파워/홈런 접촉 변동성이 살아 있으면 우선순위에서 낮춰. 구종+구속 표가 중립 위주여도 최근 장타/HR 변동성이 있으면 얇은 언더를 막는 근거로 봐.

모델 쪽 선발이 5이닝을 채우기 어렵거나 4이닝 이상 불펜 노출을 강제하는 구조라면, 필승조가 쉬었더라도 풀게임 ML은 캡해. 이때 선발 구간 엣지가 살아 있으면 F5는 별도로 유지할 수 있어.

모델 쪽 선발이 볼넷/트래픽 리스크가 뚜렷하면, 타선 매치업이 맞았더라도 ML로 자동 확장하지 말고 F5 전용인지 먼저 판단해. 불펜 품질과 후반 경로가 그 트래픽을 흡수할 만큼 강할 때만 ML을 유지해.

구종+구속 `플러스`가 많아도 최근 삼진율이 높고 상대 선발이 낯선 투구폼/작은 표본/특이 구종 비중을 가진 경우에는 F5와 ML 강도를 한 단계 낮춰. 이건 상대편을 고르는 규칙이 아니라 플러스 슬롯이 실제 득점으로 전환되지 않을 위험을 반영하는 규칙이야. 오버도 양 선발이 6이닝을 갈 수 있는데 볼넷/출루 압박이나 후반 불펜 노출이 약하면 우선순위에서 낮춰.

최근 타격감은 wOBA만 보지 말고 볼넷 압박, 하위타선 연결, 득점 전환까지 같이 봐. 최근 성적이 홈런/장타에 치우쳤고 출루 압박이나 하위타선 연결이 약하면 F5와 ML 강도를 낮춰. 기준점 8.5 이하의 얇은 언더는 한쪽 타선만 막히는 구조로는 올리지 말고, 중립-heavy 트래픽이 있으면 양 선발의 길이와 전체 불펜 안정성이 확실할 때만 유지해.

오프너/벌크/PRIM 구조에서는 벌크 투수가 실제로 중반 이닝을 안정적으로 먹을 수 있는지 O/U에 반영해. `PRIM` 표기만으로 안정 벌크로 확정하지 말고, 명확한 벌크 예정이나 최근 50구 이상 workload가 있을 때만 안정 벌크로 처리해. 근거가 부족하면 해당 투수를 예상 메인 매치업으로 쓸 수는 있지만 F5/ML/+1.5/O-U 강도는 캡해.

주전 거포 결장을 언더 근거로 자동 연결하지 마. 남은 라인업 깊이가 살아 있거나 상대 벌크/하위 불펜 붕괴 리스크가 있으면 얇은 언더는 패스하고, 오버는 한쪽 득점 경로만으로 올리지 말고 양쪽 득점 경로를 검증해.

기준점 10.5 이상의 오버에서 불펜 피로를 근거로 삼을 때는, 사용 가능한 브릿지/롱릴리프가 지친 팔들을 흡수할 수 있는지 확인해. 흡수 가능하면 단순 전날 투구수만으로 오버를 올리지 말고 pass 또는 리뷰 전용으로 내려.

확정 라인업의 구종+구속 적합도가 약한 팀이 짧은 정배라면 ML 우선순위를 캡해. 작은 표본 선발/벌크에 상대 상단 타선도 표본 부족이 많으면 `+1.5`는 커버 불확실성으로 보고 lean 이하로 낮춰.

언더독 `+1.5`는 상대를 막는 그림만으로 올리지 마. 선발 생존을 타선 상성보다 우선하고, 언더독 선발의 BB/HR 리스크가 있으면 좋은 구종+구속 상성이 있어도 lean 이하로 낮춰. 명확한 선발 붕괴 리스크가 있으면 `+1.5`는 pass 또는 리뷰 전용으로 내려. 언더독 본인 타선의 최근 득점 전환이 차갑고 자기 득점 경로가 부족한 경우도 마찬가지야.

`+1.5`는 자기 팀의 late bullpen 보호력이 있어야 해. 선발과 타선 상성이 괜찮아도 셋업/핵심 하이레버리지/마무리 경로가 접전을 보호하기 어렵다면 pass 또는 리뷰 전용으로 내려.

오버가 주로 안타/볼넷 트래픽 기대에서만 나오고 홈런/장타, 최근 득점 전환, 선발 붕괴, 명확한 6회 이후 하위 불펜 노출이 약하면 우선순위 오버로 올리지 마. 출루 기대만 높은 경기는 lean 또는 리뷰 전용으로 두고, 실제 득점 전환 근거가 있어야 해.

최종 우선순위 직전에 기존 레이어 결과를 재사용하는 입장 게이트를 한 번 적용해. 이 단계에서는 점수를 더하거나 야구 입력을 다시 계산하지 말고 상한만 적용해. 트래픽만 강하고 최근 득점 전환과 불펜 품질 우위가 모두 없는 사이드는 74점, 오프너-벌크-브리지-필승조 전체 체인이 확인되지 않은 사이드는 74점, 필승조 가용성 또는 실제 후반 품질이 부족한 ML/+1.5는 71점으로 제한해. 마이너스 5명 이상·중립 0명인 타선에 기대는 오버는 하위타선/볼넷 경로나 검증된 불펜 오버 경로가 없으면 69점으로 제한해.

애매한 추측은 실제 데이터처럼 말하지 말고, 표본 부족은 타자 약점으로 처리하지 마.

선발 HR/붕괴 리스크가 있고 상대 상단 타선 3명 이상이 구종+구속 `플러스`면 ML보다 O/U 또는 패스를 먼저 검토해. 공식 선발과 RotoWire가 충돌하더라도 명확한 벌크/PRIM 투수가 확인되어 그 투수 기준으로 분석했다면 미해결 선발 충돌로 계속 하향하지 마.
```
