## Prediction Review

- Was the starter-lineup pitch/velocity read correct?
- Did recent lineup form convert into actual run creation?
- Did starter command, HR, workload, or collapse risk behave as expected?
- Were closer, setup, and high-leverage availability assumptions correct?
- Did bridge or lower-bullpen exposure decide the result?
- Did the umpire or requested weather materially change the game?
- Was the selected betting market better than the raw game prediction?

## Error Classification

Classify each miss before proposing a change:

- Unpredictable event: injury, ejection, defensive error cluster, unusual sequencing
- Data issue: wrong lineup, wrong starter, missing opener/bulk information, stale market line
- Execution issue: correct model read but wrong market selection or price
- Model issue: repeated, explainable pattern not already represented by the model
